# GX RE Toolkit

Independent offline research toolkit for explicitly supported Mitsubishi project
formats. This is an unpublished local candidate, not a finished release.

Planned distributions are `gx3-fx5-parser-toolkit`, `gx3-r-parser-toolkit`,
`gxw-parser-toolkit` and `gx-re-lab`. Installation and compatibility instructions
will be added with verified artifacts; no functionality is claimed by this skeleton.

This project is unofficial and is not affiliated with or endorsed by Mitsubishi
Electric. It provides no field acceptance or safety approval. Never apply output
to live equipment without independent engineering verification. No PLC connection
or engineering-software automation belongs to the default runtime or tests.

Private original projects, official exports, customer data and vendor materials
are not distributed. Public synthetic regression is not official conformance.

## Local recovery

This checkout has its own Git database. A parent repository does not back up its
files or commits. Keep explicit-ref Git bundles outside both working trees and
verify each by an independent restore. A local backup is not off-device protection.
Do not use recursive cleanup on a containing directory: double-force Git cleanup
can remove a nested repository even when ordinary cleanup skips it.
